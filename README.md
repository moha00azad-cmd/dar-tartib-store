# دار الترتيب

متجر إلكتروني احترافي لبيع منتجات تنظيم وتخزين المنزل في السوق المغربي.

## المميزات
- تصميم عربي RTL كامل
- متوافق مع الهاتف المحمول
- قسم هيرو احترافي
- تصنيفات ومنتجات وعروض
- سلة شراء
- نموذج طلب سريع بدون تسجيل
- الدفع عند الاستلام
- واجهة لوحة تحكم إدارية نموذجية
- إعدادات جاهزة للتوسع في المستقبل

## التشغيل محليًا

1. افتح المجلد في المتصفح مباشرة، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8000
```

2. افتح الرابط:

```text
http://localhost:8000
```
